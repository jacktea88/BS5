# Session Export Package

這個資料夾是本次 Chat 工作階段的可攜式匯出包，適合直接複製到其他專案工作區中使用。

## 內容
- `chat-transcript-verbose.md`：接近逐字流程的整理版聊天紀錄
- `chat-backup.md`：結構化的會話備份
- `prompt-template.md`：可直接重用的提示詞範本
- `project-files.md`：本次實作過的頁面、CSS、圖片與搬移說明

## 如何匯入到其他專案
1. 把整個 `export-package` 資料夾複製到新的工作區。
2. 若要延用實際網頁成品，另外一起複製 `test2` 資料夾與 `ch07/images` 圖片資料夾。
3. 先打開 `project-files.md`，確認要帶走的 HTML、CSS 與圖片檔案清單。
4. 若要重用提示詞，直接打開 `prompt-template.md`。
5. 若要回顧這次對話，先看 `chat-transcript-verbose.md`。
